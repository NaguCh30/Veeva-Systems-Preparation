# Veeva Systems Preparation

This repository contains my preparation for **Veeva Systems**.

The preparation is organized **day-wise** and focuses on building strong
foundations in problem solving, Data Structures & Algorithms, Java,
Object-Oriented Programming, SQL, and DBMS.

The purpose of this repository is to consistently practice, track progress,
and strengthen concepts required for technical interviews.

---

## 📚 Areas of Preparation

- Data Structures & Algorithms (DSA)
- Java
- Object-Oriented Programming (OOP)
- SQL
- DBMS
- Problem Solving
- Logical Thinking
